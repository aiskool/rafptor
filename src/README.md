# Source code

Core Rafptor platform source code.

## Planned modules

- `parser/` — AFP/MO:DCA parser (Java)
- `mapper/` — Font mapping engine (Python)
- `converter/` — AFP → PDF conversion pipeline (Java)
- `validator/` — Automated QA system (Python)
- `collector/` — Mainframe resource collector agent (RPGLE/JCL)
- `transport/` — Built-in secure transfer module replacing Axway Transfer CFT (Go or Rust, SFTP/TLS 1.3)
- `api/` — Backend REST API (Spring Boot / Node.js)
- `dashboard/` — Frontend application (React/TypeScript)
