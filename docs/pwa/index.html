SaaS de Migration AFP

Plateforme de migration automatisee liberant les entreprises de deux verrous couteux : IBM AFP (format documentaire) et Axway Transfer CFT (~75K$/an de licence MFT). Pipeline integre de bout en bout, du mainframe au PDF.

Pipeline de migration
01 — Client
Agent collecteur
Deploye sur IBM i / z/OS — inventorie et exporte les flux AFP et toutes les ressources referencees via un canal securise.
Fonction
Export des flux AFP, polices (raster, outline, TrueType), overlays, form definitions, page definitions et page segments depuis les bibliotheques mainframe (FONTLIB, OVLYLIB, PSFLIB).
Technologies
RPGLE / CL JCL / REXX SFTP chiffre
Risque
Modere
Necessite un acces aux bibliotheques de ressources sur le mainframe du client et une expertise IBM i/z/OS.
02 — Transport
Transfert securise integre
Remplace Axway Transfer CFT — module leger base sur SFTP/TLS 1.3, livraison garantie, checkpoint/restart, chiffrement AES-256, audit complet. Zero licence MFT supplementaire.
Remplace Transfer CFT
Module de transfert purpose-built integre a la plateforme. Protocoles ouverts uniquement (SFTP, HTTPS). Livraison garantie avec checkpoint/restart, retry automatique, verification d'integrite SHA-256 et recus de transfert signes. Aucune licence MFT tierce requise.
Economie client
Elimine ~180K$/an de couts Transfer CFT : licence (~75K$), support (~30K$), ingenieur MFT dedie (~75K$). L'economie sur le transport seul finance la migration AFP.

ROI immediat
Technologies
Go ou Rust SFTP TLS 1.3 AES-256
03 — Ingestion
Parsing et normalisation
Parsing MO:DCA complet, resolution des ressources externes, deduplication des polices et graphiques, classification par complexite.
Sous-architectures parsees

GOCA graphiques vectoriels

BCOCA codes-barres
FOCA metriques de polices
CMOCA gestion couleurs
MOCA metadonnees
Classification
Chaque document est automatiquement classe :

Simple Polices standard, pas de ressources externes

Moyen Polices custom, overlays, ressources externes

Complexe Pages fax/image, PDF embarques, DBCS
Technologies
Java 17+ Parseur custom Apache PDFBox
Alpheus (reference)
04 — Analyse
Mapping intelligent
Mapping deterministe des polices IBM standard + mapping assiste par IA/vision par ordinateur pour les polices custom. Generation du rapport d'audit.
Polices standard
Base de donnees couvrant les polices IBM standard (quelques centaines). Mapping deterministe vers TrueType/OpenType equivalents avec metriques de positionnement validees.
Polices custom — IA
Comparaison des glyphes AFP raster avec des polices TrueType candidates via vision par ordinateur. Scoring de similarite et proposition automatique.

Risque eleve Differenciateur competitif majeur.
Technologies
Python PyTorch OpenCV scikit-learn
05 — Conversion
AFP vers PDF
Transformation via une representation intermediaire XML/JSON preservant toute la semantique, puis generation PDF haute fidelite avec polices embarquees.
Representation intermediaire
Chaque flux AFP est decompose en XML/JSON structuree : texte positionne, polices, images, overlays, codes-barres, metadonnees TLE/NOP. Format agnostique permettant de cibler plusieurs sorties.
Generation PDF
PDF haute fidelite : polices embarquees (TrueType subset), images optimisees, metadonnees preservees. Support PDF/A-1b pour archivage long terme (ISO 18565). Cible : milliers de pages/minute.
Technologies
Java Apache PDFBox iText (alt.) XML / JSON
06 — Validation
QA automatisee
Triple validation (visuelle, structurelle, metadonnees) avec scoring de confiance et routing automatique/humain.
Comparaison visuelle
Rasterisation de l'AFP original (via emulateur IPDS) et du PDF genere. Comparaison pixel par pixel avec calcul de score SSIM. Seuil configurable par client.
Validation structurelle
Verification de la presence et du positionnement de tous les elements : texte, images, codes-barres, overlays. Comptage d'objets et verification des coordonnees.
Routing
Score ≥ seuil Validation automatique

Score < seuil Revue humaine assistee

Cible : 80% de validation automatique.
07 — Interface
Dashboard et reporting
Suivi de progression en temps reel, metriques qualite, gestion des exceptions et file de revue humaine.
Suivi migration
Vue d'ensemble : applications migrees, en cours, en attente. Progression par lot, estimation du temps restant, historique des executions.
Metriques qualite
Taux de validation automatique, score moyen de fidelite, types d'erreurs les plus frequents, tendances de qualite sur le temps.
